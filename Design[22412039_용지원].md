# 1. Introduction

Personal Task Manager는 사용자가 자신의 업무와 일정을 효율적으로 관리할 수 있도록 지원하는 개인 작업 관리 시스템이다.

본 시스템은 다음 기능을 제공한다.

* 작업 생성(Create)
* 작업 수정(Edit)
* 작업 삭제(Delete)
* 작업 완료 처리(Complete)
* 작업 검색(Search)
* 작업 필터링(Filter)

사용자는 작업의 우선순위(Priority)와 마감일(Deadline)을 설정할 수 있으며, 모든 데이터는 브라우저의 Local Storage에 저장된다.

본 Design 문서는 Analysis 단계에서 정의된 기능을 실제 구현 수준으로 구체화하기 위해 작성되었으며, Class Diagram, Sequence Diagram, State Machine Diagram 및 구현 요구사항을 정의한다.

| Storage          | Local Storage |

---

## Nonfunctional Requirements

### Maintainability

모듈화된 구조를 사용하여 유지보수가 용이해야 한다.

### Performance

1000개 이상의 작업 데이터에 대해 빠른 검색 속도를 제공해야 한다.

### Security

사용자 데이터는 로컬 저장소에만 저장된다.

### Accessibility

키보드 탐색 및 기본 접근성 요구사항을 만족해야 한다.
